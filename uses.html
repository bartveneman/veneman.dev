Uses

No-one ever asks me what software or hardware I use, so I'll write it down here.

Editor & terminal

  1. 💾 Visual Studio Code is my default editor. It allows me to do pretty much anything I want. That includes using Atom keybindings. Theme: GitHub Dark Default, because of the slightly higher contrast than most themes.

Apps

  1. 🦊 Browser: Firefox.
  2. 🎛️ Web dev browser: Polypane.
  3. 🟦 Whenever I see someone dragging their windows across their monitor manually, I cringe. What a waste of time and energy. Rectangle has made my life so much easier, allowing me to instantly make windows full-screen, half-screen, top-half-screen and more with only a handful of keyboard shortcuts.
  4. 🎸 Spotify. Not a single day goes by without it.
  5. 🦆 DuckDuckGo is a good replacement for Google Search. Very rarely (< 1 × per week) need I search something via Google. DuckDuckGo respects my privacy, is pretty fast and gives proper search results, while displaying very minimal, non-targeted ads.

Hardware

  1. 💻 MacBook Pro
  2. ⌨️ Apple keyboard, without numpad
  3. 🖱️ Logitec MX Master 3S
  4. 🎧 I can't do a day of coding without my Sennheiser PXC 550. Sound quality and noise cancellation are top notch! Durability is great as well as I've had mine for over 8 years now and it's still as good as day one.
  5. 🔊 Desktop sounds comes through the great Ruark Audio MR1 mk2 speakers that are placed below my screen.
  6. 📺 I treated myself to a Philips B-line 346B1C monitor since I've been Working From Home and I'm loving it. Power, network and display all in a single USB-C cable on a larger-than-strictly-necessary screen. Pricy but worth it!
  7. 🎙️ Mic: Razer Siren Mini
